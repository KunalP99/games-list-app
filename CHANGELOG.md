# Changelog

All notable changes to **GamesList** are documented here, newest first.

---

## [Unreleased]

### Added
- **Names on Recent Activity link to profiles.** Clicking a friend’s name or avatar in the feed opens their profile; clicking your own opens My Games.
- **Bursts of activity stack into one row on Recent Activity.** Finishing a game can trip five achievements at once, and an import session adds a run of backlog games — either used to bury everything else under a wall of near-identical rows. Both now collapse into a single entry per person per day: "You unlocked 5 achievements", "You added 7 games to backlog". The first three are named as chips and the rest hide behind a "+N more" button — click it to reveal them all in place, "Show less" to collapse again — and a batch of unlocks totals its XP. Achievements and backlog adds stay in separate rows, completions and wheel spins are never stacked, and grouping happens before the feed is trimmed so a burst costs one row instead of crowding other activity out.
- **Show your password while signing in.** The password box on the login page now has an eye button that reveals what you've typed, so a failed sign-in isn't a guess about which character went wrong. Starts hidden, and resets to hidden if you switch between Sign in and Sign up.
- **Steam's review verdict on the game detail page**, replacing the IGDB critic and user scores that used to sit in the same place. The About card's Details block now shows what Steam players make of a game — e.g. "Overwhelmingly Positive · 98% of 1,039,977" — coloured by Steam's own positive/mixed/negative split. No new API key: the Steam app id comes free with the IGDB details already fetched for that card, and Steam's review endpoint is keyless. Games with no Steam release, or fewer than 10 reviews, simply don't show the row, and a failed lookup hides it rather than erroring. Cached for a day per game.
- **Turn wheel turns off if you don't want to take part.** A new **Wheel** section in Settings switches wheel turns on and off per person. With it off, the Wheel tab disappears from the nav (desktop and mobile), `/wheel` redirects to the dashboard, the "Current Turn" card and "Spin the Wheel" quick action leave the dashboard (the remaining cards stretch to fill the row rather than leaving a gap at the end), and your turn badge stops showing on your profile. **You keep earning tickets exactly as before**, and **your current turn is saved** — switch it back on and you pick up on the same turn you left. Wheel History stays available either way, and your past spins stay in everyone else's history. Turning it off mid-spin discards that unfinished spin but keeps the turn itself. Requires SQL: `ALTER TABLE public.profiles ADD COLUMN IF NOT EXISTS wheel_enabled BOOLEAN NOT NULL DEFAULT true;`
- **Mark a game as a favourite while completing it.** The "Mark as Completed" modal now has a **★ Favourite** toggle alongside the rating, hours and review, so you can flag a game you loved without a separate trip to the edit form afterwards. It starts in whatever state the game is already in, so opening the modal on a game you'd previously favourited shows it already on.
- **My Games now opens with your own profile banner.** The same weekly-rotating banner and headline stats (completed, hours, average rating, games at 100%, tickets) shown on friends' profiles now lead your own games list too — the "My Games" title, Import/+ Add Game buttons, and everything below (Now Playing, filters, the list itself) are unchanged, just sitting under it. No "What they play"/Recent Activity cards or wheel-turn badge here — banner and stats only.
- **Friend profiles look like profiles now.** Opening someone from the Friends list no longer shows a games list with a header stuck on top. The page leads with a banner built from one of their 5-star games, rotating to a different one each week. Prefers a live screenshot of that game over its stored key art/box art, since screenshots usually don't carry a baked-in title or logo that would clash with the text overlaid on the banner, their avatar carries an XP level ring, and their headline numbers (completed, hours, average rating, games at 100%, tickets) sit right on the banner. Below it, an even row of cards for whatever they're playing right now (most recently started first), and a pair of cards — titled outside the box, matching the dashboard's section style — holding a **"What they play"** taste profile of their top genres plus a **Recent Activity** recap (their last few completions, drops, wheel spins, and achievement unlocks, built on the same feed logic as the site-wide Activity page) with a "View more" link through to it. Their games list and its filters are unchanged, just moved into the main column. Everything accented uses *their* accent colour, not yours.
- **End-to-end tests for the wheel's resumable turns** — a small Playwright suite (`npm run test:e2e`) drives a real browser against the local dev database to prove the save-close-reopen loop actually works: entry lists, elimination runs, and paid spins all survive a genuine tab close, and a finalized turn doesn't resurrect. Hard-refuses to run against anything but the local test database.
- **The wheel remembers where you were.** Closing the tab mid-turn no longer loses it — your entry list, spin mode, elimination progress, and a result waiting to be accepted all come back exactly as you left them. Halfway through an elimination run, the same games stay knocked out and the same game still wins. A resumed turn shows what it has already cost you in tickets. Requires SQL: `ALTER TABLE public.profiles ADD COLUMN IF NOT EXISTS wheel_session JSONB;`
- **Local test database** — a full Supabase stack (Postgres, Auth, API, Studio) now runs locally in Docker, so new features can be tested without touching real data. `npm run env:dev` / `npm run env:prod` switch which database local dev talks to, `npm run db:reset` rebuilds the local schema from migrations generated out of production, and `npm run seed:dev` fills it with fake users and games. A "🧪 TEST DATABASE" pill shows in the corner whenever the app is pointed at the local stack (never in production).
- **Emulated flag** — a new "🕹️ Emulated" toggle in the add/edit game form's Flags row, for marking a game as played via emulation. Requires SQL: `ALTER TABLE public.games ADD COLUMN IF NOT EXISTS is_emulated BOOLEAN NOT NULL DEFAULT false;`
- **Search your backlog on the wheel page** — the "Your Backlog" panel on `/wheel` now has a search box to filter the list down by title before adding games to the spin list.
- **Wheel: "Add all" and "Random 5" backlog shortcuts** — the "Your Backlog" panel on `/wheel` now has two buttons: **Add all** adds your whole backlog to the spin list in one click, and **🎲 Random 5** adds 5 random backlog games — clicking it again swaps out the 5 it added last time for a fresh random 5 instead of piling on top.
- **Steam Deck achievements** — a new "Steam Deck" achievement category: complete games on Steam Deck (Deck Debut → Couch Commander → Portable Pro → Deck Devotee → Deck Legend at 1/5/10/25/50), log Steam Deck hours (Handheld Hours 50h, Battery Drainer 250h, Powered by Valve 500h), plus Perfect on the Deck (100% a game on Steam Deck), Deck Collector (20 library games marked Steam Deck), and Big Screen, Small Deck (complete the same game on Steam Deck and another platform).
- **Steam Deck flag** — mark a game as one you play on your Steam Deck. There's a "Steam Deck" toggle in the add/edit game form and a "Playing on Steam Deck" checkbox in the add-to-backlog review modal, and games marked this way show a Steam Deck icon on their detail page. Requires SQL: `ALTER TABLE public.games ADD COLUMN IF NOT EXISTS steam_deck BOOLEAN NOT NULL DEFAULT false;` and a `public/steam-deck.png` icon.
- **Review modal on every add-to-backlog** — adding a game to your backlog from anywhere except the add-game form (the "More from this developer" row, the Most Anticipated carousel, another user's game page, and friend recommendations) now opens the same review modal used by the wheel: preview the game's details, pick a cover image, and choose a **required platform** before it's added. Free-text games with no linked database entry still add directly.
- **Showcase-live notifications** — when a gaming industry showcase (Gamescom ONL, Future Games Show, etc.) is happening **today**, everyone gets a notification ("<event> is live today"). Detected by a daily Vercel Cron (`/api/cron/check-events`) from IGDB's events, announced once per event. Requires SQL (a small `notified_events` table).
- **Release notifications** — when a game from your backlog that wasn't out yet finally releases, you get an in-app alert. A new **notification bell** in the nav shows an unread badge and a dropdown of your alerts ("<game> is out now"), each linking to the game; opening the panel marks them read. The dropdown shows the most recent few with a **"Load more"** button to page through older ones. Generated by a daily Vercel Cron (`/api/cron/check-releases`) so they appear even if you weren't in the app. Requires SQL (new `notifications` table + `games.release_notified` column) and `CRON_SECRET` + `SUPABASE_SERVICE_ROLE_KEY` on Vercel (already set).
- **Unreleased backlog games are handled separately.** A backlog game whose release date is still in the future is now split into its own **"Coming Soon"** section on the games list (each card shows when it releases), keeping it out of the main backlog you can actually play. It's also **hidden from the wheel's backlog picker** until it's out — once its release date passes, it moves into the normal backlog and appears on the wheel automatically (games with no release date are always treated as available).
- **"Most Anticipated" games carousel on the dashboard** — a big-banner carousel of the 12 most-hyped upcoming games (IGDB's pre-release hype ranking), one game at a time with its key art, title, and release date (or "TBD"); switch games with the arrows or dots (auto-advances too). Each banner has an **"+ Backlog"** button that opens a review modal (developer, release date, genres, an image picker, and a **required platform**) before adding it to your backlog. Sourced live from IGDB (cached hourly), so the list and its dates update automatically as IGDB changes them.
- **"More from this developer" on the game detail page** — a horizontally-scrolling row of the other mainline games by the game's developer (e.g. CD Projekt RED's Witcher and Cyberpunk games), newest to oldest, each with an **"+ Backlog"** button to add it straight to your backlog. Sourced live from IGDB, filtered to main games only (no DLC, expansions, special editions, or cancelled titles), unreleased titles show "TBD", and the section is hidden when there's no developer or no other games.
- **Richer "About" on the game detail page** — the About card now also shows the game's **involved companies with their logos and roles** (Developer / Publisher / Porting / Support) and a **Details** block (game modes, player perspective, themes, franchise, engine, critic score, and IGDB user score with the number of users). Fetched live from IGDB per game (no new columns); the card gracefully shows only whatever data exists.
- **Upcoming gaming events on the dashboard** — a new card sitting beside "Friends Activity" always shows 5 industry showcase events (Gamescom Opening Night Live, Future Games Show, etc.) — the soonest upcoming ones first, with recent past events filling any remaining slots shown struck-through. Each row has a calendar-style date badge, a relative countdown ("in N days" / "N days ago"), and per-network watch links (Twitch / YouTube / Twitter), falling back to a single "Watch" link when only a stream URL is available. On the day an event happens, its row is highlighted. Sourced from IGDB's `events` endpoint (cached hourly), it streams in so it never delays the rest of the dashboard and simply hides itself if there's nothing upcoming. (The "Recommended by your friends" carousel is temporarily hidden — the code is kept behind a flag.)
- **Hours played per year** on the Completed list — each year header now shows the total hours played across that year's games at the far end, next to the game count (in all three views — capsule, box art, and table).
- **Review a wheel game before it's added** — when the wheel gives you a game (accepting a spin, a spin+reroll choice, a paid Spin&Reroll upgrade, a paid Choose-a-Game, or the Choose turn), a modal now previews it (cover, developer, release date, genres — read-only), lets you **pick the card image** from the game's artwork/screenshots (or paste your own URL), and asks you to pick a **platform (required)** before it's added to your library as Playing. Cancelling changes nothing — and on the paid paths, no tickets are spent unless you confirm. Custom/free-text wins (which aren't added to your library) skip the modal and finalize as before.
- **"Mark as DNF" button** on the game detail page — for a game you're Playing, a red DNF button sits next to Mark as Completed. It asks "Are you sure?" (Yes/No) before dropping the game; confirming applies the DNF penalty and (if it was your most recent wheel pick) hands your wheel turn back.
- **DNF a wheel-won game to get your turn back** — if you DNF the game the wheel just gave you (on a spin, spin & reroll, or choose turn), your wheel turn reverts to the turn that produced it, so you can spin/choose again instead of losing the turn. Only the **most recent** wheel outcome counts — if you've spun or chosen again since, DNF-ing the older game does nothing. Tickets spent that turn are not refunded (and the usual DNF penalty still applies). Requires SQL: `ALTER TABLE public.profiles ADD COLUMN IF NOT EXISTS pending_wheel_game_id UUID, ADD COLUMN IF NOT EXISTS pending_wheel_turn TEXT CHECK (pending_wheel_turn IN ('spin','spin_reroll','choose'));`
- **Pick from your backlog on the wheel's Choose turn** — the Choose-your-next-game screen now shows your whole backlog as a grid of covers alongside the search box, so you can click a game to play instead of typing it. Choosing one flips that backlog game to Playing. (Also fixed backlog games' identity on the wheel so IGDB-linked ones correctly auto-add/flip when chosen or won.)
- **"Also played by" card** on the game detail page — a small card under the About section listing other users who have the same game (currently playing it or completed it), with their avatar, name, and status, linking to their profile. Sits in the right sidebar on wide screens (under Dates on mobile). Currently-playing users are shown first.
- **Playlists auto-sync from YouTube** — a daily Vercel Cron job (`/api/cron/sync-playlists`) mirrors every playlist that was imported from a YouTube playlist against its source: new videos are pulled in, videos removed upstream are dropped, and order is kept. Works for both the Videos-page playlists (those whose "Watch on YouTube" link is a playlist) and game-page playlist media. Quota-friendly — one batched `playlists.list` reads up to 50 playlists' video counts per call, and only playlists whose count changed are re-fetched. Needs `YOUTUBE_API_KEY`, `SUPABASE_SERVICE_ROLE_KEY`, and (recommended) `CRON_SECRET` on Vercel. SQL: `ALTER TABLE public.playlists ADD COLUMN IF NOT EXISTS youtube_item_count INTEGER, ADD COLUMN IF NOT EXISTS synced_at TIMESTAMPTZ; ALTER TABLE public.games ADD COLUMN IF NOT EXISTS youtube_item_count INTEGER;`
- **Infinite scroll on game search** — every game search bar (the add/edit form, and both wheel search boxes) now loads more results as you scroll to the bottom of the dropdown, instead of stopping at the first handful. Backed by a paginated `/api/rawg/search` (`page` param + `hasMore`) shared via `fetchGameSearchPage`.
- **Pick a game's image** in the add/edit form — after choosing a game from search, a gallery of its IGDB artworks and screenshots appears; click one to set the game's banner (used on the list card and the detail-page hero). Defaults to the auto-selected key art, so leaving it alone keeps the previous behaviour. Backed by a new `/api/rawg/images/[id]` route and `getGameImages`.
- **Artwork banner** on the game detail page — the hero now uses IGDB's official landscape key art (like igdb.com game pages), falling back to a screenshot. Stored in a new `games.artwork_url`.
- **Box Art view** for the games list — a third layout alongside the capsule and list views: a grid of portrait cover art with the same info (title, developer, status, hours, rating, achievements, badges) below each. Games without a cover show a placeholder tile. Covers come from IGDB and are stored in a new `games.cover_image_url`; the toggle persists via the `gameView` cookie.
- **IGDB metadata provider** — game search, enrichment, cover art, and screenshots can now be sourced from IGDB instead of RAWG (set `METADATA_PROVIDER=igdb` with `IGDB_CLIENT_ID`/`IGDB_CLIENT_SECRET`), added because RAWG's API went down. Same shapes and UI; games store an `igdb_id`. Note: IGDB has no achievements data (that section is hidden) or dominant colour. Flip the flag back to `rawg` if RAWG returns — existing data is untouched.
- Games: **add YouTube media to a game** — paste a single video *or* a playlist URL in the game form. A playlist pulls in all its videos; a single video adds just that one. The game page shows a single large player for one video or a carousel for several (click-to-play lightbox), plus a watch-on-YouTube link for playlists. Anything you add to a game **also appears on the Videos page automatically** (one row per game, linking back to it). Stored in `games.youtube_videos`.
- Videos page: **search + sort**. A search box finds any matching video across all sources (standalone, playlists, and games) and shows them as a flat grid; clearing it returns to the carousels. A Newest/Oldest sort orders the rows (and search results) by when the media was added.
- Videos: **import a whole YouTube playlist** — in the playlist builder, paste a YouTube playlist link and hit Import to pull in all its videos (title + watch-on-YouTube link pre-filled); edit or remove any before creating. Uses the YouTube Data API (`YOUTUBE_API_KEY`).
- **Videos page** (`/videos`) — a curated library of YouTube videos and in-site playlists you and your friends have made. Everyone can browse; a curator (admin) adds entries by pasting a YouTube URL, with the title, thumbnail, and channel fetched automatically from YouTube. Video cards are click-to-play (thumbnail swaps to an inline player). Playlists are built here from individual videos (via a "Make a playlist" toggle), expand inline to reveal their videos, and can carry an optional YouTube playlist link for a "watch on YouTube" option. Backed by new `videos` + `playlists` tables and a `profiles.is_admin` curator flag.
- Wheel history now shows the **action actually taken** rather than only the turn type — a paid Spin Again reads "Spin Again", a paid Choose a Game reads "Chose a Game", etc. Backed by a new `wheel_spins.finalized_via` column; older spins fall back to their turn-based label.
- On a Spin + Reroll history card where the user rerolled, the game they rerolled **away from** (the runner-up) is now highlighted, making it clear which game was chosen over the other.
- Wheel history now shows a **full breakdown of every paid action in a turn**, one row each — so spinning again (−3) and then paying to choose a game (−9) reads as two separate lines rather than a single misleading "−12". Repeated actions collapse with a count (e.g. "You spun again (×2) −6"). Backed by a new `wheel_spins.ticket_spends` column; older spins fall back to a single aggregate row.

### Changed
- **Pages open faster.** Every page load used to wait on the notification bell’s data and a changelog lookup before anything could render — four Supabase round trips stacked up before the first pixel, on every navigation. The nav and page now render as soon as your profile is loaded, and the bell streams in a beat later, so switching pages (the add-game form and games list especially) feels quicker. The bell also does two queries instead of three.
- **Wheel history reads as a timeline instead of a card grid.** Spins were laid out as cards in a grid, and a grid row stretches every card to match the tallest one in it — so a Choose turn with nothing but a result got padded out with a block of dead space to line up with a Spin & Reroll carrying a skipped-turn note, paid-action rows and a list of the other games on the wheel. It's now one continuous log where each entry is only as tall as what it has to show: a plain result is a single line, and the spend breakdown and wheel list appear underneath only when they exist. Your own spins stay tinted with your accent colour so they're still easy to pick out among everyone else's.

### Fixed
- **CSV-imported games now get box art.** The spreadsheet importer (`/import`) was already fetching a portrait cover image from RAWG/IGDB but throwing it away — only the landscape banner (`image_url`) was ever stored, never `cover_image_url`. Since Box Art is the default games-list view, every imported game rendered as a blank placeholder tile regardless of how good the enrichment match was. It now stores the cover too.
- **Wheel history's badges no longer change colour depending on who's looking.** "Spin" used `brand-*`, which follows the logged-in viewer's own accent colour — so the same badge could render as any hue depending on who opened the page. It's fixed blue now (the same blue `StatusBadge.tsx` uses for "Playing"), and "Choose" is teal — clear of Reroll/Skip's amber and the ticket-award emerald too. Fixing this surfaced a real bug along the way: `tailwind.config.ts`'s `content` globs never scanned `lib/`, where these badge classes actually live — any class here that didn't *also* happen to appear verbatim in an already-scanned file silently never got compiled at all, which is why an earlier emerald attempt looked washed out and a pink one rendered with no colour whatsoever. `lib/**` is now included.
- **"Games Completed Per Year" no longer strands its bars at opposite edges.** With only one or two years of history, the chart used to spread them evenly across the card's full width, leaving a big empty gap between them. It now sizes itself to roughly one slot per year — bars stay a consistent width and packed from the left — and only grows to the full card width once there are enough years to fill it.
- **Choosing a game on a Choose turn no longer reads as "spun the wheel" in Recent Activity.** A Choose turn never spins — you pick directly — but its history row was being lumped in with real spins, so the feed said "spun the wheel → <game>" either way. It now says "chose <game>", on your own profile, friends' profiles, the dashboard, and the site-wide Activity page alike.
- **No more pointless final spin on a one-game wheel.** When a paid Spin & Reroll's elimination run narrowed down to a single remaining game, it still made you click "Spin again" for a wheel with only one possible outcome. It now settles straight to the result, matching what the free spin and paid Spin Again already did.
- **The Entries list now matches the wheel.** Games taken off the wheel — whether eliminated this round, rejected by paying to spin again, or already locked in as a Spin & Reroll option — now show crossed out in the side list instead of looking like they're still in the running, and the count reads as remaining-of-total (e.g. "Entries 3/5"). The "N games remaining" line and the list are now driven by the same source, so they can't disagree.
- **The wheel could freeze completely mid-spin.** In elimination mode, repeatedly paying to Spin & Reroll (and its "spin for the next game" follow-ups) could hang the wheel animation forever with no error — the game it was supposed to land on had been silently excluded from its own set of options, so it could never find where to stop. Reachable by continuing to spend tickets on Spin Again / Spin & Reroll across several rounds, exactly as far as the tickets allowed.
- **Paid wheel spins could take your tickets and lose the result.** Spin Again (−3) and Spin & Reroll (−6) deducted tickets and then returned the game they picked *only* in the page's response — it was never saved anywhere. If the tab closed, the connection dropped, or the browser crashed before you finished the turn, the tickets were gone with nothing to show for them and no entry in your wheel history. Paid results are now recorded in the same moment the tickets are spent. Ticket deductions are also checked for failure now, instead of carrying on as though they'd worked.
- **A friend's profile "Now Playing" section was capped at 2 games.** It now shows every game they're currently playing, matching your own `/games` page.
- **Game completions weren't earning tickets.** The recent DB cleanup dropped `profiles.tickets_earned_total` as apparently unused (nothing in the app read it) — but the `award_tickets` Postgres function still wrote to it internally, so every ticket award started failing silently the moment that column was dropped. The column has been restored, and `awardCompletionTickets`/`reverseGameCompletionTickets` now surface RPC errors instead of swallowing them, so a failure like this is loud next time. Balances affected during the gap were corrected.
- **Activity feed no longer shows old DNF games as "DNF'd today."** DNF entries are now dated by the game's drop date (falling back to when it was added), instead of last-modified — so editing a DNF'd game no longer bumps it to the top of the feed as if it were just dropped.
- **Wheel-assigned achievements now unlock.** The wheel wasn't tagging the games it gave you (the `assigned_by` field the achievements check was never written), so "Obedient", "Willing Participant", "True Believer", and "Assigned and Loving It" could never be earned. Wheel wins are now marked as assigned, and existing wheel wins were backfilled.
- **Paid wheel spins no longer re-land on a game you've already seen this turn.** When you spend tickets to Spin Again or upgrade to Spin & Reroll, the game(s) landed on earlier this turn are excluded from the new spin, so paying never just hands you the same game back. (Free first spins and the elimination reel are unchanged; the exclusion resets when you start a new spin.)
- **Wheel wins now save the game's full details.** When you added a game to the wheel from search (not already in your backlog) and it won, the new "Playing" entry was missing its **developer** — and also its box-art cover and artwork banner. The auto-add now fills those in from the game's metadata, so a won game looks the same as one added via the form. Games flipped from your backlog were already complete and are unaffected.
- **Ticket achievements** (First Earnings / Getting There / Century Club / Ticket Hoarder) now track your **true lifetime tickets earned**, summed from the ledger, instead of the cached `profiles.tickets_earned_total` column — which was never kept in sync (the `award_tickets` RPC only updates the spendable balance), so the achievements under-counted and unlocked late. They now reflect every ticket you've earned and can't drift; existing totals were corrected to match the ledger.
- Games added to the backlog from the "Recommended by your friends" card now carry their RAWG id (and are enriched with description/colour/release date). Previously they were saved without a RAWG link, so on the wheel they showed no cover art and — when won — were not added to your library as Playing. Now they display their cover and correctly flip to Playing on a win.
- Wheel now builds its list from RAWG search — a search box with a live dropdown replaces the free-text games box; picking a result adds a real game (with cover art), and you can still press Enter to add a custom title for anything not on RAWG. Backlog games can be one-click added and carry their RAWG identity.
- Wheel winners auto-add to your library as "Playing" — on the **spin**, **spin & reroll**, and **choose** turns, the game you end up with (including the paid "Choose a Game" option, now RAWG-searchable) is added to your library. A won game already in your **backlog** flips to Playing; a game you've already **Completed** starts a fresh entry flagged as a replay; games already Playing (or a replay in progress) or DNF are left untouched. Custom free-text entries still win but aren't added. This applies to both the wheel result and the Choose turn. Existing copies are matched by RAWG id, falling back to a case-insensitive title match so older/imported entries without a RAWG link are still recognised.
- "What's New" popup — appears on authenticated pages after a new release for 7 days, backed by the `changelog_entries` table; includes a "Don't show again" checkbox that stores the dismissed entry's id in localStorage
- "Date Started" field on the game form (shown for any non-backlog status); on the game detail page, completed games now show how many days it took to complete (start date → completion date)
- Public/private toggle for notes on the game form — defaults to Public for new games; public notes are visible to everyone viewing the game, private notes only to the owner. Existing notes remain private by default.
- RAWG search dropdown on the wheel's "Choose your next game" input — picking a result auto-adds the game to your library with status "Playing" and today's start date. If the game already exists in your library it switches to Playing instead of duplicating. Free-text confirmations still work as a fallback.
- User dropdown on the navbar — clicking the avatar circle opens a panel with user info, Settings link, theme toggle, and sign out
- `/settings` page with three sections: Profile (display name), Security (password change), and Appearance (theme preference + accent colour picker)
- `ThemeInitialiser` component — applies the user's saved theme preference from the database on every page load, keeping localStorage in sync
- Accent colour persisted in `profiles.accent_colour` — used for the avatar circle in the dropdown and as a tinted row highlight on the Ticket History page
- Dynamic brand palette — the entire `brand-*` Tailwind colour scale (buttons, badges, focus rings, gradients, text) now adapts to the user's saved accent colour via CSS custom properties; the Settings colour picker shows a live preview as you drag
- 23 new achievements across all categories: completion milestones up to 500 games, 100% completions up to 100 games, replays up to 30, hours up to 2,500, 10-platform variety, library size up to 1,000 games, and several dedication/misc additions
- Mark as Completed modal on the game detail page — prompts for hours, star rating (half-star support), achievement progress, and completion date before saving; star fill uses the user's accent colour gradient
- Dashboard bar chart and radar chart now use the user's accent colour instead of the hardcoded orange
- Achievement toast popup is now clickable — navigates to `/achievements` and scrolls directly to the unlocked achievement card; a "View →" label appears on hover
